# 🚗 SafeRide

A simple, mobile-friendly ride-hailing web app for Nigerian states — built with **pure HTML, CSS & JavaScript**. No backend, no server, no login required. All data is persisted in the browser via `localStorage`.

## ✨ Features

- 📍 **11 Nigerian States** — Anambra, Lagos, Abuja, Port Harcourt, Delta, Ibadan, Osun, Abia, Enugu, Ebonyi, Sokoto
- 🚗 **3 Ride Types** — Economy, Comfort, XL with live fare estimates
- 🔍 **Driver Matching Simulation** — auto-assigns a driver ~4 seconds after booking
- ❌ **Cancel Ride** — with confirmation dialog before cancelling
- 📋 **Ride History** — all past rides stored and shown with status
- 💾 **LocalStorage Persistence** — data survives page refresh
- 📱 **Mobile-first Design** — works great on any phone screen

## 🚀 Usage

Just open `index.html` in any browser — no install, no server needed.

## 🛠 Tech Stack

- HTML5
- CSS3 (custom properties, flexbox, grid)
- Vanilla JavaScript (ES6+)
- localStorage API
